# 錄影帶租借管理系統
使用 C#、ASP.NET Core MVC 與 SQL Server 製作的課堂專案，
練習影片資料展示、拷貝庫存狀態、會員資料查詢及租借流程。

## 使用技術
- C#
- ASP.NET Core MVC（.NET 8）
- HTML
- SQL Server
- Visual Studio

## 程式實作內容
以下依目前原始碼整理，網站尚未在本機測試資料庫環境完成執行驗證：

- 顯示影片編號、片名、類型、分級與導演。
- 顯示影片各份拷貝的媒體種類與在架／借出狀態。
- 選擇會員，將可借出的拷貝登記為借出。
- 查看會員基本資料及目前租借的影片。
- 以彈出視窗展示入庫時間與代理商示範資料。

## 資料庫設計
包含三張主要資料表：

| 資料表 | 用途 |
| TableVideos_1131619 | 記錄影片編號、片名、類型、分級與導演 |
| TableMembers_1131619 | 記錄會員代號、姓名、電話、加入日期、點數與地址 |
| TableVideoCopies_1131619 | 記錄各份拷貝所屬的影片、媒體種類、入庫日期及目前借閱會員 |

### 關聯說明
- **影片與影片拷貝為一對多關係：**
  一部影片可以有多份拷貝，
  透過影片拷貝資料表的 `vNo` 外鍵連結影片資料表。
- **會員與影片拷貝為一對多關係：**
  一位會員可以同時租借多份拷貝，
  透過影片拷貝資料表的 `mId` 外鍵連結會員資料表。
- 每份拷貝最多記錄一位目前借閱會員；
  未借出時，`mId` 為空值。

目前資料結構記錄的是當前借閱狀態，
並非完整的歷史租借紀錄。

### 建表與測試資料
專案內的 `SQLQuery1.sql` 提供建表指令與測試資料。
目前已在本機 SQL Server 的 `VideoRentalDemo` 資料庫
建立三張資料表及外鍵關聯，並匯入：
- 2 筆會員資料
- 3 筆影片資料
- 4 筆影片拷貝資料

## 執行環境與限制
- Visual Studio，需安裝 ASP.NET 與網頁開發工作負載。
- .NET 8 SDK。
- SQL Server。

原始開發環境連接課程提供的資料庫，
本儲存庫不提供原資料庫連線帳密。
目前已完成本機測試資料庫建置，
但網站尚未完成本機連線與完整操作驗證，
因此暫無網站操作截圖或示範影片。
如需執行：
1. 在自己的 SQL Server 建立專用測試資料庫。
2. 在空白測試資料庫執行 `SQLQuery1.sql`。
3. 使用 Visual Studio 開啟 `WebApplication1.sln`。
4. 透過本機 User Secrets 設定
   `ConnectionStrings:DefaultConnection`。
5. 執行網站，進入 `/Order/Index` 查看影片列表。
